War story

The Assets pallet signing bug.

pdk (Python)

"bad signature" at the RPC layer

pdk-ts (TypeScript)

signs the identical call — success

Root cause: Portaldot's metadata says one balance field is bigger than it actually is. Python signs it at the wrong size — 8 extra bytes — so what it signed no longer matches what the chain checks against.
